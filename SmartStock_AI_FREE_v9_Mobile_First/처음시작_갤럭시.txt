SmartStock AI FREE 8.0 — 삼성 갤럭시에서 사용하기

먼저: 다운로드한 ZIP은 휴대폰 앱이 아니라 웹사이트를 만드는 프로그램 파일입니다.
처음 한 번은 PC로 GitHub 업로드를 하는 편이 훨씬 쉽습니다.

1단계: SmartStock_AI_FREE_v8_MultiTimeframe.zip 파일을 휴대폰의 '내 파일 → 다운로드'에서 선택합니다.
2단계: '압축 풀기'를 누릅니다. 폴더 안에서 app.py, requirements.txt, timeframe.py 파일을 찾습니다.
3단계: https://github.com 에 회원가입하고 새 저장소 'smartstock-ai'를 만듭니다. 비공개 저장소를 권장합니다.
4단계: 압축을 푼 파일을 저장소에 올립니다. app.py가 저장소의 맨 위에 있어야 합니다. .github 폴더도 업로드하세요. 휴대폰에서는 여러 폴더 업로드가 어려워 PC 사용을 권장합니다.
5단계: https://share.streamlit.io 에 GitHub로 로그인하고 Create app → 저장소 선택 → Main file path에 app.py → Deploy를 누릅니다.
6단계: 웹사이트 주소가 생기면 갤럭시 크롬에서 그 주소로 들어갑니다.
7단계: 사이드바에서 종목 검색 → 원하는 종목 선택 → '차트 주기 선택'에서 1분봉 / 5분봉 / 15분봉 / 30분봉 / 1시간봉 / 일봉 / 주봉 / 월봉 선택합니다.
8단계: 맨 위의 '차트' 탭에서 캔들과 보조지표를 보고, '예측', '옵션', '위험', 'AI 학습·검증' 탭에서 더 살펴봅니다.

검색 예시:
- 코어위브: CRWV
- 엔비디아: NVDA
- 애플: AAPL
- 삼성전자: 005930.KS
- SK하이닉스: 000660.KS

주가 데이터를 '갱신 및 재학습' 버튼으로 새로 요청할 수 있으나, 무료 자료가 진짜 실시간인 것은 아닙니다.
차트를 분봉으로 바꾸어도 1주~1년 예측은 '일봉 데이터'로 분석합니다.

오류가 나면 오류 메시지를 캡처해서 ChatGPT에 보내주시면 됩니다.
비밀번호나 Telegram Bot Token은 보내지 마세요.
