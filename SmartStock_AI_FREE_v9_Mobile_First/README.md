# SmartStock AI FREE 9.0 — 갤럭시 모바일 우선

**미국·한국 주식 검색, 분봉/시간봉/일봉 차트, 기술지표, 옵션, 가격기반 머신러닝, 예측 기간 변경, 과거 검증을 한 곳에서 보여주는 Streamlit 웹 프로그램입니다.** 안드로이드 APK가 아니며 설치 없이 보려면 웹사이트 배포가 필요합니다.

## 8.0에서 바뀐 실제 화면 구성

- PC처럼 왼쪽 사이드바를 열지 않고 **맨 위에서 종목 검색** 및 관심 종목 원터치 선택: CRWV, NVDA, TSLA, AAPL
- **AI 예측 기간**과 **차트 봉 주기**를 화면 맨 위의 큰 선택창으로 변경
- 현재 종가·모델 상승 방향 점수·판단 보류/참고 신호를 **두 칸씩** 표시
- `📈 차트 / 🔮 예측 / 📌 옵션 / ☰ 더보기`의 큰 터치 메뉴. 더보기에는 뉴스·재무·위험·AI 해설·학습 검증·종목 비교
- **차트 보조지표 표시/숨김**을 접을 수 있는 메뉴로 이동
- 차트 표시량 기본값 120개 봉, 확대·이동용 제스처 적용(Plotly 브라우저의 동작은 기기에 따라 달라질 수 있음)
- 9개의 긴 가로 탭 제거: 필요한 한 분석 화면만 그리도록 변경
- CSV/가상 데이터·수동 티커·새로고침은 **고급 설정** 아래로 이동
- 모바일에서 너무 좁게 나오던 4칸 지표를 **2칸씩** 배치

기존 8.0의 계산 엔진, 옵션 체인 조회, 선택 기간(1~252거래일) 머신러닝, SEC/GDELT 과거자료 수집, 신호 검증 등은 그대로 포함합니다. **예측은 확정 일봉 기반**이고 차트만 분봉/시간봉으로 변경됩니다. 분봉에 대한 실시간 AI 예측이 검증된 것은 아닙니다.

## 갤럭시에서 먼저 화면을 체험하는 가장 간단한 방법

1. `휴대폰_미리보기.html` 파일을 갤럭시에서 Chrome 같은 브라우저로 열어보세요.
2. `CRWV`, `NVDA`, `TSLA`, `AAPL` 버튼을 눌러보세요.
3. 차트 봉 주기, 예측 기간, `차트·예측·옵션·더보기`를 바꿔 보세요.

**중요:** HTML은 조작 방식의 **오프라인 가상 체험판**입니다. 실제 시세, 뉴스, AI 학습, 백테스트를 실행하지 않습니다. 모든 숫자는 예시입니다. 실제 분석하려면 아래 Streamlit 앱을 웹에 배포해야 합니다.

## 진짜 분석 프로그램을 모바일 웹사이트로 실행하기

1. GitHub 무료 계정을 만드세요.
2. 이 ZIP 파일을 갤럭시의 '내 파일'에서 압축 해제합니다.
3. GitHub 웹사이트에서 **새 Repository**를 만든 뒤, 압축을 푼 폴더의 파일들을 저장소 최상단에 업로드합니다. `.github/workflows` 폴더 구조를 유지합니다. (`app.py`, `engine.py`, `mobile_ui.py`, `requirements.txt`가 같은 루트에 있어야 합니다.)
4. [Streamlit Community Cloud](https://share.streamlit.io/)에서 GitHub 저장소를 연결하고 실행파일 `app.py`를 선택한 다음 배포합니다.
5. 만들어진 HTTPS 웹 주소를 갤럭시 Chrome으로 엽니다. Chrome 메뉴(⋮) → **홈 화면에 추가**를 선택하면 앱 아이콘처럼 바로 실행할 수 있습니다.

공개 GitHub 저장소에 개인 API 키, 전화번호, 비밀번호 등을 올리지 마세요. 무료 호스팅의 절전 및 데이터 저장 제한, yfinance 무료 분봉 기간 제한이 있습니다.

## 테스트 및 주의 사항

- 기존 엔진 + 모바일 화면 라우팅 단위 테스트는 `python -m pytest -q`로 실행할 수 있습니다.
- 모바일 시연 HTML은 390px 휴대폰 브라우저 에뮬레이션에서 기본 조작과 가로 스크롤 유무를 확인했습니다.
- 이 환경에는 Streamlit/yfinance 실행 라이브러리가 설치되지 않아 **실제 Streamlit 화면 배포와 실시간 시세 조회는 검증하지 못했습니다**. 따라서 모바일 HTML 체험 화면과 실제 앱 UI의 픽셀 단위 일치를 보장하지 않습니다.
- 1분봉 등은 데이터 제공처 제한으로 일부 종목·기간에서 실패할 수 있습니다. 실제 거래소 실시간 호가 및 무중단 학습 서버가 포함된 것은 아닙니다.
- 모델이 출력하는 숫자는 투자 성공 확률을 보장하지 않으며, 신호 검증이 부족하면 '판단 보류'를 기본으로 합니다.
