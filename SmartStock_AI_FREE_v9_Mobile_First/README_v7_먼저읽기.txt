SmartStock AI FREE 7.0 — 무료 과거 데이터 검색 보강

중요: 안드로이드 APK가 아니라 Python+Streamlit 웹앱 소스코드입니다. 이전 6.0을 대체합니다.
클라우드 배포 및 실제 Yahoo/GDELT/SEC 네트워크 호출은 제작 환경에서 테스트할 수 없었습니다.

[왜 새 버전인가?]
기존 6.0: 옵션+뉴스 관측이 일정 기간 함께 쌓여야 외부데이터 AI 점수를 검증함.
새 7.0: 옛날 뉴스 제목은 GDELT 공개 검색 서비스에서 직접 조회해 날짜별로 수집하고,
        SEC 공시는 당시 실제 공시 제출일 기준으로 조회합니다.
        옵션 과거 체인이 없어도 뉴스+가격 또는 공시+가격 모델을 별도로 검증할 수 있습니다.
        시장상황에 따라 가격 모델보다 예측 성적이 나쁘면 결과는 숨깁니다.

[쉬운 사용법: 배포된 Streamlit 웹 화면]
1. 왼쪽 종목 선택에서 CRWV, NVDA 등 원하는 티커를 고릅니다.
2. 상단에서 예측 기간을 지정합니다.
3. '🧠 학습·검증' 탭에서 '무료 과거 뉴스 검색해서 학습자료 채우기' 클릭.
4. 과거 3~24개월 중 기간을 고르고 검색 회사 이름이 정확한지 확인합니다.
5. 'SEC 과거 재무 공시 무료 검색·저장'도 필요한 경우 클릭합니다.
   SEC 조회는 SEC_USER_AGENT 환경변수에 본인 이메일을 포함한 신원정보가 필요합니다.
6. 기록 일수, 비활성/검증불통과/검증통과 등의 상태를 확인합니다.

[Github Actions로 여러 해 검색]
저장소 Actions -> Historical news backfill (manual) -> Run workflow ->
티커, 회사 이름, 날짜 입력 -> 실행.
GDELT 요청수가 제한되므로 한 번에 전 기간이 검색되지 않을 수 있습니다.
재실행하면 이미 저장된 날짜는 중복 추가하지 않습니다.

[데이터 특성 및 위험]
- GDELT는 과거 뉴스 제목/링크/기사 최초 포착시각을 제공하는 검색 색인입니다.
  모든 신문이나 기사 전문을 확보하거나 무조건 정확한 뉴스 감성을 판별하는 AI가 아닙니다.
  회사명이 흔하면 다른 기사도 섞입니다. 사이트 API가 작동하지 않거나 기간 제한이 있으면 오류로 표시합니다.
  기사 제목이 오늘 수정됐다면 과거 정확한 원본 제목이 아닐 가능성도 남습니다.
- 날짜별 검색 성공과 검색 자료 없음은 구분합니다. 요청 실패를 0건 뉴스로 채우지 않습니다.
- 모든 과거 0일/미래일을 임의로 만들지 않고 뉴스의 GDELT 최초 포착 날짜 다음 거래일부터 사용합니다.
- SEC는 과거 공시의 filed(제출) 날짜를 기준으로 가격 일봉과 결합합니다.
  공시 완료일 이전 시점에는 그 수치를 절대 넣지 않습니다.
- **개별 옵션의 과거 만기별 전 종목 IV/OI/체결/호가 전체는 무료로 자동 복원이 안 됩니다.**
  Cboe 공개 통계 중 일부는 시장 전체 거래량/풋콜 비율이고 개별 종목 전체 옵션 체인이 아닙니다.
  이 자료가 없어도 가격+뉴스와 SEC 학습을 시도합니다.
- 분석은 과거 가격으로 신호 적합성을 평가할 뿐 확실한 상승 확률이나 수익을 보장하지 않습니다.
- 무료 클라우드의 파일 저장은 재시작/재배포 시 유실될 수 있습니다. 기록을 계속 남기려면
  Github Actions 수집 결과를 저장소에 커밋하는 방식으로 쓰세요.
- 실시간 스트리밍 주문흐름과 24시간 무중단 AI 서버는 여전히 제공하지 않습니다.

[실행/검증]
PC에서 pip install -r requirements.txt
streamlit run app.py
소스 검사: python -m py_compile *.py
자동 테스트: python -m pytest -q (개발 환경에서 31개 통과)
